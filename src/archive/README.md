# Archived UI

Components here are **disabled** on the live site but kept for reference.

## TikTokHighlights

The TikTok section was removed from the main layout. To show it again:

1. In `App.js`, add: `import TikTokHighlights from './archive/TikTokHighlights';`
2. Render `<TikTokHighlights />` where you want it (e.g. after `<Header />`).
